# Flywheel 학습 원장

하네스가 스스로 좋아지게 만드는 유일한 살(spoke)이다. AI가 만든 PR이 리뷰에서 지적을 받으면
**고치고 끝내지 말고**, 왜 처음부터 그렇게 못 썼는지를 여기에 한 줄 남긴다. 같은 패턴이 2회
누적되면 규칙으로 승격시켜, 다음 PR에서는 애초에 틀리지 않게 한다.

```
Rule(CLAUDE.md) → Skill/Agent → 구현 → Hook(측정) → Review(피드백) → Learn(이 문서) ─┐
        ↑                                                                            │
        └──────────────────────── 2회 반복 시 승격 ───────────────────────────────────┘
```

## 기록 방법

리뷰 피드백을 반영하는 커밋을 만들 때, 아래 표에 행을 **append**한다(기존 행 수정 금지).

- **기록 대상**: 컨벤션 위반, 반복될 수 있는 판단 실수, 하네스(훅/스킬/에이전트) 자체의 빈틈
- **기록 대상 아님**: 일회성 오타, 그 PR에만 해당하는 로직 실수
- `누적`이 2 이상이 되면 즉시 승격한다. 승격 = CLAUDE.md 또는 해당 SKILL.md 본문에 규칙 문장을
  추가하고, 여기 `상태`를 `승격 → <어디에>`로 바꾼다. 이 한 번의 수정만 원장의 예외다.
- 승격된 항목은 지우지 않는다. 규칙이 왜 생겼는지가 규칙 자체보다 오래 쓸모 있다.
